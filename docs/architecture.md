# System Architecture

The architecture documentation has moved to **[`../ARCHITECTURE.md`](../ARCHITECTURE.md)** (repository root), which is kept current with the code.

OpenOutFind is a browserless **lead finder** — **define ICP → discover (licensed data) → qualify → rank → (optionally) resolve an address → export CSV** — with no social-network account and no scraping. It does not send email. See `../ARCHITECTURE.md` for the module map, the deal state machine, the cycle, and the ML pipeline.
